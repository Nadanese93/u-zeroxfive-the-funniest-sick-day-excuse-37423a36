One line under 200 characters that gets you out of work and gets a laugh: a sick-day excuse a boss might half believe, with the twist landing at the end. The program writes the excuse to `entry.txt`.

> Locked myself out of my own apartment and the locksmith can't come till noon. Technically I'm homeless until then.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
